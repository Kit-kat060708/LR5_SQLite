# Лабораторная работа №5
## Знакомство с базами данных. Puthon и SQLite

**Вариант:** 2
**Тема:** Спортивный инвентарь

### Описание проекта
Программа создает базу данных SQLite для хранения информации о спортивном инвентаре.

### Структура таблицы equipment
| Поле | Тип | Описание |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY | Уникальный номер |
| name | TEXT | Название инвентаря |
| category | TEXT | Вид спорта |
| value | INTEGER | Количество единиц |

### Выполненные операции
1. Создание таблицы equipment.
2. Добавление восьми записей.
3. Вывод всех записей.
4. Выбор инвернтаря категории "Футбол"
5. Фильтрация по количеству больше 5.
6. Сортировка по количеству в порядке убывания.
7. Изменение количества инвентаря по id.
8. Удаление записи по id.

### Запуск программы
Для запуска необходим Python 3.
В терминале выполните команду python main.py.
База данных app.db создается автоматически при первом запуске программы.
